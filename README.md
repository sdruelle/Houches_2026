# Turbulence Analysis - Les Houches 2026

This repository contains Python tools for analyzing turbulence in astrophysical simulations. It is currently adapted specifically for processing outputs from the **Ramses** code.

## Features

* Analysis of hydrodynamical and MHD turbulence (e.g., interstellar medium, star formation).
* Reading and processing Ramses AMR (Adaptive Mesh Refinement) outputs.
* Computation of power spectra and probability density functions (PDFs) for gas density and velocity fields.

## Setup

Clone the repository to your local machine:

```bash
git clone https://github.com/sdruelle/Houches_2026.git
cd Houches_2026
```

Ensure you have a working Python 3 environment with standard scientific libraries:
```bash
pip install numpy scipy matplotlib
```
